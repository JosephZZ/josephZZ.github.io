Understanding the Riemann Hypothesis Proof

A readable map of the formal Lean 4 proof of the Riemann Hypothesis in leanprover-community/riemann-hypothesis. The proof, about 17 million lines of Lean, is reorganized into a tree of meaning units. For each step the map shows what it must prove, how it is proved, and which parts are new to this proof. The code is only reorganized, never changed.

The interactive map and the method notes will appear here.

理解黎曼猜想的形式化证明

把约 1,700 万行的 Lean 形式化证明，重新组织成一棵由意义单元构成的树：每一步要证明什么、怎么证明、哪些是本证明特有的。代码只重新组织，内容一字不改。

交互式证明地图和方法说明即将上线。
